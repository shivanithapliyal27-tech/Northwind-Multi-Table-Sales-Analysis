# Northwind Multi-Table Sales Analysis

## Project Overview
This project analyzes Northwind sales data using Microsoft SQL Server and Power BI. It combines multiple related tables to explore sales performance, product performance, customer purchasing patterns, monthly sales trends, and shipping metrics.

## Objectives
- Analyze sales data using multi-table SQL joins.
- Calculate total sales, orders, customers, and units sold.
- Identify the top 10 products and customers by sales.
- Analyze monthly sales and product-category performance.
- Review shipping status and average shipping duration.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft SQL Server
- SQL
- Microsoft Power BI
- Power Query
- CSV

## Analysis Performed
1. Multi-table sales details
2. Sales KPI summary
3. Top 10 products by sales
4. Monthly sales analysis
5. Top 10 customers by sales
6. Sales by product category
7. Shipping analysis

## Power BI Dashboard
The dashboard includes KPI cards for Total Sales, Total Orders, and Total Units Sold, along with charts for monthly sales, top products, top customers, and category-wise sales.

### Interactive Slicers
- Filter by Year
- Filter by Product
- Filter by Customer

This project demonstrates an end-to-end data analytics workflow, from SQL-based data analysis to an interactive Power BI dashboard for exploring sales performance across products, customers, and time.
